# 蓝象智联｜数字驾驶舱 V2（中英对照版）

Static single-page dashboard. Served with GitHub Pages.

- Entry: `index.html`
- Assets: `assets/`

## Language toggle

- Top-right control cycles `中/英` (bilingual) → `中文` → `EN`.
- The choice is persisted in `localStorage`; a URL parameter also works: `?lang=both`, `?lang=zh`, `?lang=en`.
